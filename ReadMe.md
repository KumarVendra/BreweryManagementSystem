# Lemon Jelly Cafe Management

This project is a simple Cafe Management backend system.  
It supports the full set of CRUD operations using Node.js, Express, and MongoDB.

## Features

### • Create  
Used for creating a new product in the system.

### • Read  
Used for reading and displaying existing products.

### • Update  
Used for updating details of a product.

### • Delete  
Used for deleting a product from the system.

## Tests

Unit tests are implemented to validate all CRUD operations.
